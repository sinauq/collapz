# Collabz
A simple tool for collaboration between researchers working on a shared project.

This tools is born out of my frustration when I tried to write a project proposal with a colleague for the first time. But also because recently I was doing more LISP coding and I felt my JavaScript is getting rusty.  

The tool will act as a note sharing and mind mapping. This is a list of feature and my own wishes:
- Users can create notes and can link them together.
- They can also import their personal notes from docx, md, org, and also annotations from Zotero.
- They can view the note graph, discover similarities and differences, and find possible connections that they can later order into a final project.

Effectively I hope that it will be a assistant tool to find frictions faster, and build on them towards a collaborative project. The main target audience I had in mind when developing was research in humanities and social sciences. So if you are a humanities or social scientist and experienced troubles or have some ideas, I would be happy to hear from you.
